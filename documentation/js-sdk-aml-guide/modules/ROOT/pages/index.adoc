= Introduction

The JavaScript SDK lets you load Aspect Models in JavaScript and TypeScript applications.
It reads Aspect Models written in RDF/Turtle (SAMM 2.0.0, 2.1.0 and 2.2.0) and returns them as typed TypeScript objects.
You can traverse these objects, or process them with a visitor, to access the model's information, such as properties, characteristics, entities, units, descriptions and constraints.

This lets you build generic frontends that adapt to the underlying Aspect Model automatically.
For example, when a new property is added to the model, the UI can show the corresponding value together with the property's name, description and unit without any code changes.

== Getting Started

=== Install from GitHub release repository

[source,shell,subs="attributes+,+quotes"]
----
npm install https://github.com/eclipse-esmf/esmf-sdk-js-aspect-model-loader/releases/download/v{esmf-sdk-js-aspect-model-loader-version}/esmf-sdk-js-{esmf-sdk-js-aspect-model-loader-version}.tgz
----

The package is named `@esmf/sdk-js` (formerly `@esmf/aspect-model-loader`).

NOTE: The package is published as an ES module only and requires Node.js 24 or newer. CommonJS consumers can load it via `require()` on Node.js 22.12 or newer.

== Usage

[source,typescript]
----
import {AspectModelLoader, Aspect} from '@esmf/sdk-js';
----

This package contains two methods for loading Turtle (.ttl) files (string value of the .ttl files).
Each method is available as a Promise-based variant and as an RxJS Observable variant.

Load an aspect model which is self-contained (includes no imports to other ttl file):

[source,typescript]
----
const aspect: Aspect = await new AspectModelLoader().loadSelfContainedAspect(ttl);

// or as Observable
new AspectModelLoader().loadSelfContainedModel(ttl).subscribe((aspect: Aspect) => {
...
});
----

or if the model contains imports to additional ttl files:

[source,typescript]
----
const aspect: Aspect = await new AspectModelLoader().loadAspect('<aspect-model-urn>', ttl1, ttl2, ttl3);

// or as Observable
new AspectModelLoader().load('<aspect-model-urn>', ttl1, ttl2, ttl3).subscribe((aspect: Aspect) => {
...
});
----

Errors are reported as typed error classes (for example `UnsupportedVersionError`, `AspectNotFoundError` or `MultipleAspectsFoundError`), all derived from `AspectModelError`.

If you are using external .ttl files you may need to parse the contents of these files to strings, to be passed to the methods params.

== Helpful functions

This module exposes some helper functions that can be used to find items inside the loaded ttl object.

Find a specific model element, and returns it or undefined.

[source,javascript]
----
let specificElement = loader.findByUrn(options.urnSelectedModelElement)
----

Find a specific model element by name, and returns the found elements.

[source,javascript]
----
let specificElement = loader.findByName(options.selectedModelName)
----
